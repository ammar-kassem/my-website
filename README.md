# موقع Portfolio عربي لمطوّر مواقع مستقل

موقع ثابت (Static) بـ HTML وCSS وJavaScript فقط، دون أي Framework أو خطوة بناء. يدعم RTL بالكامل ويعمل بفتح `index.html` مباشرة أو برفع المجلد إلى أي استضافة ثابتة.

## هيكل الملفات

```
index.html            المحتوى والأقسام (نصوص قابلة للتعديل مباشرة)
assets/css/style.css  التصميم (الألوان في متغيرات :root أعلى الملف)
assets/js/config.js   الإعدادات: الاسم، واتساب، Calendly، العملات، الدفع
assets/js/projects.js مصفوفة المشاريع
assets/js/main.js     السلوك: القائمة، المعرض، الاستثمار، الأسئلة الشائعة
assets/img/           ضع فيه صور المشاريع المصغرة
```

## الإعداد المطلوب قبل النشر

افتح `assets/js/config.js` وعدّل:

1. `brand.name` و`brand.role`: اسمك وصفتك.
2. `whatsapp.number`: رقمك بالصيغة الدولية بأرقام فقط (مثال `9665XXXXXXXX`).
3. `calendly.url`: رابط صفحة الحجز في Calendly.
4. `currency` و`projectTypes`: العملات وأنواع المشاريع في قسم الاستثمار.

أي قيمة تُترك فارغة تُخفي العنصر المرتبط بها تلقائيًا. إذا لم يُضبط واتساب ولا Calendly تظهر في قسم التواصل رسالة «قنوات التواصل قيد الإعداد».

في `index.html` حدّث أيضًا عنوان الصفحة ووصف SEO في `<head>` (`title`, `description`, `og:*`) ليطابق اسمك. وعند النشر أضف `canonical` و`og:image` برابط موقعك.

## إضافة مشروع

عدّل `assets/js/projects.js` فقط. انسخ القالب الموجود في أعلى الملف داخل المصفوفة:

```js
window.PROJECTS = [
  {
    id: "project-1",
    name: "اسم المشروع",
    category: "صفحات هبوط",
    thumbnail: "assets/img/project-1.jpg",
    description: "وصف مختصر.",
    problem: "المشكلة (اختياري).",
    solution: "الحل (اختياري).",
    technologies: ["HTML", "CSS", "JavaScript"],
    previewUrl: "https://example.com",
    status: "published" // published | inProgress | prototype
  }
];
```

- أزرار التصفية تُبنى من قيم `category` تلقائيًا، وتظهر عند وجود أكثر من تصنيف.
- إن لم توجد `thumbnail` أو تعذّر تحميلها يظهر بديل بسيط.
- `previewUrl` يقبل روابط `http/https` فقط، وإلا يُخفى زر المعاينة.
- المعرض فارغ افتراضيًا ولا توجد مشاريع تجريبية. أضف مشاريع حقيقية فقط.
- أسماء حالات النشر تُعدَّل من `statuses` في `config.js`.

## قسم الاستثمار والدفع

- القسم يتحقق من المدخلات (مبلغ صحيح، نوع المشروع) ويعرض ملخصًا مع رابط واتساب برسالة جاهزة، ويوضح أن إدخال المبلغ لا يعني الدفع ولا الالتزام.
- نص رسالة واتساب قابل للتخصيص من `whatsapp.investmentMessage` بالمتغيرات `{type} {amount} {currency} {idea}`.
- **الدفع معطّل** (`payment.enabled: false`) ولا يوجد أي تنفيذ دفع حقيقي.
- لربط بوابة دفع لاحقًا: فعّل `payment.enabled`، ثم عرّف الدالة `window.startPayment(summary)` لتستدعي نقطة نهاية في خادمك (Backend) تنشئ جلسة الدفع. **لا تضع مفاتيح الدفع السرية في ملفات JavaScript أبدًا**؛ يجب أن تبقى في الخادم.

## تعديل النصوص والألوان

- النصوص موجودة في `index.html` وكل قسم معلَّم بتعليق. النصوص المقترحة (الأسئلة الشائعة، أسلوب العمل، وصف الخدمات) صيغة أولية فعدّلها لتعبّر عن التزاماتك الفعلية، خصوصًا ما يخص التكلفة والمدة والتسليم.
- الألوان في `:root` أعلى `style.css`.
- الخط: IBM Plex Sans Arabic من Google Fonts (يحتاج اتصالًا بالإنترنت، ويوجد خط احتياطي للنظام).

## الجودة

- تصميم Mobile-First ومتجاوب، ودعم لوحة المفاتيح (رابط تخطي، تركيز ظاهر، Esc لإغلاق النوافذ).
- عرض بيانات المشاريع عبر `textContent` دون `innerHTML`، والتحقق من الروابط.
- تحميل كسول للصور، واحترام `prefers-reduced-motion`.
- لا تقييمات ولا إحصائيات ولا شهادات.

## النشر

ارفع المجلد كاملًا إلى GitHub Pages أو Netlify أو Vercel أو أي استضافة ثابتة. لا يحتاج إلى أي أوامر بناء.
